# DEADROLL – Devil Dice-style swipe puzzle (prototype)
Single-file Three.js prototype (`index.html`). Portrait, swipe a die to roll it. Match N dice showing N to sink them; a 1 touching a sinking chain wipes all 1s.
Run locally: `python3 -m http.server` and open index.html. Test: `python3 test.py <url>` (Playwright).
